# Changelog

## v0.1.0 — Preview

First downloadable release of **logic sim CE**.

- Switches, lights, AND/OR/NOT/NAND/NOR/XOR/XNOR and buffer gates.
- Thin wires that leave building cells free; fanout and cycle rejection.
- 6×4, 9×6 and 12×8 boards, automatic scrolling and safe resizing.
- 16-step undo; AND, half-adder and full-adder examples.
- CRC-protected alternating circuit saves and legacy-save migration.
- Custom 16×16 Cesium icon and spaced `logic sim CE` description.
- Shared-C desktop preview, host tests and public installation/development docs.

Native build and desktop checks pass. Calculator hardware testing remains pending.
